# CrunchWhistle — 2600 Hz whistle → WOPR

A phone-phreaking homage. Whistle 2600 Hz into a coin-op payphone and WOPR from *WarGames*
answers. Everything runs on one headless Mac mini: Asterisk, the AudioSocket daemon, local
speech recognition, a Votrax-style voice, and a local LLM.
